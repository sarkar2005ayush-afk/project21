TOP PROGRAM - FEATURES
======================
Legend:  DONE = implemented in top_simple.c     TODO = not implemented yet


1. UPTIME, IDLE TIME AND IDLE PERCENTAGE ______________________________ DONE
   Command : cat /proc/uptime
   Shows   : uptime as hh:mm:ss
             idle % = (idle_time / num_cores) / uptime * 100
   Colour  : green (> 80%), white (> 20%), red (otherwise)


2. MEMORY INFORMATION _________________________________________________ DONE
   Command : cat /proc/meminfo
   * RAM  used / total (GB)   ->  MemTotal - MemAvailable
   * Swap used / total (GB)   ->  SwapTotal - SwapFree


3. NUMBER OF CORES ____________________________________________________ DONE
   Command : cat /proc/cpuinfo   (the "siblings" line)
   Fallback: sysconf(_SC_NPROCESSORS_ONLN)


4. CPU USAGE (AVERAGE + CORE WISE) ____________________________________ DONE
   Command : cat /proc/stat   (better than /proc/loadavg, gives core wise usage)
   Shows   : vertical bar + percentage for AVG and for every core
             (top-right corner, busiest core is drawn in red)


5. POWER AND BATTERY __________________________________________________ DONE
   Command : cat /sys/class/power_supply/BAT1/status          (charging / discharging)
   Command : cat /sys/class/power_supply/BAT1/capacity        (battery percentage)
   Command : cat /sys/class/power_supply/BAT1/capacity_level  (battery level)
   Shows   : status - percentage (level)
             blinking red when below 20% and discharging

   * Command : cat /sys/class/power_supply/ACAD/uevent
     (power plugged on or off)                                           TODO
   * Command : cat /sys/class/power_supply/BAT1/uevent
     (all battery details)                                               TODO


6. PROCESS LIST _______________________________________________________ DONE
   Source  : every numbered folder in /proc
   Files   : /proc/<pid>/stat       -> name, state, priority, nice, cpu %, running time
             /proc/<pid>/status     -> VmSize (virtual), VmRSS (resident)
             /proc/<pid>/loginuid   -> user id (name looked up with getpwuid)
   Columns : PID, USER, PRI, NI, VIR(mb), RES(mb), STATE, CPU%, TIME+, PROGRAM
   Note    : processes without VmSize/VmRSS (kernel threads, zombies) are hidden


7. SYSTEM INFORMATION _________________________________________________ TODO

             -s  kernel name

             -r  kernel release

             -p  processor type (non-portable)
             -i  hardware platform (non-portable)
             -o  operating system
   (In C this can be done with uname() from <sys/utsname.h>)
